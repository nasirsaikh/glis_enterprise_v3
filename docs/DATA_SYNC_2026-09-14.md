# Updated content synchronization - 2026-09-14

This update merges the content from the supplied updated `glis_enterprise_v3` ZIP into the newer repository schema instead of replacing newer application code.

## What is imported

`core/migrations/0010_import_updated_zip_content.py` loads the supplied SiteSettings, services, features, statistics, general/medical process steps, testimonials, FAQs, management team, insurer partners, provider types, locations, specialties, network providers and their M2M relations, TPA services, medical contacts, and download-center content.

The old `HeroSection` values are mapped to the hero fields now stored on `SiteSettings`. The old `MedicalProcessStep` rows are mapped to the unified `ProcessStep` model as `CLAIM` and `PREAUTH` processes. Legacy `HomeSection` rows are archived under `data/content_archive/` because the latest schema intentionally removed that model.

## Media cleanup

Referenced logo, hero, management, insurer-logo and download-document assets from the ZIP are included. Image assets are stored as optimized WebP files and the imported database paths point to those files. Two stale references (`cms/features/newplot_17.png` and `cms/testimonials/photo_XqVDECj.jpg`) were cleared because those source files were not present in the supplied ZIP.

## Applying the update

Run the normal Django migration command:

```bash
python manage.py migrate
```

Migration `core.0010_import_updated_zip_content` is idempotent for the supplied primary keys and updates the content rows to match the supplied snapshot.
